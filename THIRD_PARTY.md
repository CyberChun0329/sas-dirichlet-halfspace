# External dependencies and licenses

The existing MIT license applies to the author's software and documentation.
MPFR/GMP and the system BLAS/LAPACK/Accelerate libraries are linked externally;
their own licenses and platform requirements apply. Original Fortran source
notices are preserved. The `vendor/` directory contains research-source
dependencies, with their recorded scientific release identity.

The paper's numerical inputs are the polynomial profiles, geometries and query
sets specified in the manuscript and supplementary material. They are supplied
with the selected task and reference files described in `REPRODUCING.md`.
